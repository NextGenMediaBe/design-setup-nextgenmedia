# _inbox

Dropzone. Gooi hier alles in wat nog verwerkt moet worden: zips, losse bestanden,
screenshots, links (in een `.md`-bestandje), geëxporteerde skills.

Zeg daarna tegen Claude: **"verwerk de inbox"**.

Het proces staat in [`07-workflows/ingest-material.md`](../07-workflows/ingest-material.md):
uitpakken → inventariseren → filteren → op de juiste plek zetten → index bijwerken → pushen.

## Regels

- Archieven (`.zip`, `.rar`, `.7z`) worden **niet** gecommit — die staan in `.gitignore`.
  Ze worden uitgepakt in een tijdelijke map, de inhoud wordt geplaatst, het archief gaat weg.
- Niets blijft hier permanent staan. Een volle inbox betekent dat er werk open staat.
- Links kun je gewoon in de chat plakken; die hoeven niet in een bestand.
